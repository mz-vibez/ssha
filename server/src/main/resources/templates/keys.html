Import a key

An Ed25519 or RSA (2048 bits or more) private key: an OpenSSH key file (~/.ssh/id_ed25519, ~/.ssh/id_rsa; passphrase-protected or not), PKCS#1 or PKCS#8 PEM. It is read and encrypted on this phone; the server only gets the public key and the encrypted private key.

How to use a key

Add the key's line to ~/.ssh/authorized_keys on a server (or as an SSH key on GitHub), run ssha-cli agent on your computer and point SSH_AUTH_SOCK at the socket it prints. Sign requests then show up on the Requests page for you to approve.
